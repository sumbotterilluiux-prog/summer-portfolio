# Fonts Directory

## Add Satoshi Font Here

1. Download Satoshi from: https://www.fontshare.com/fonts/satoshi
2. Extract the files
3. Copy these files to this directory:
   - `Satoshi-Variable.woff2` (recommended - includes all weights)

   OR individual weight files:
   - `Satoshi-Regular.woff2`
   - `Satoshi-Medium.woff2`
   - `Satoshi-Bold.woff2`

## Current Setup

The portfolio is configured to use Satoshi Variable font.
If the font file is missing, it will fall back to system fonts.
